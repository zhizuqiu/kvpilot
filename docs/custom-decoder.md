# 自定义数据解码器（Custom Decoder）

KVPilot 支持把键值内容按自定义命令解码后再展示，例如把 protobuf、msgpack、自定义二进制
协议转换成人可读的 JSON。该能力沿用自 Tiny RDM 1.2.7，行为一致。

## 使用步骤

1. 打开「偏好设置 → 自定义解码」，点击「新增自定义解码」。
2. 填写解码器信息：

| 字段 | 说明 |
| --- | --- |
| 名称 | 展示用的解码器名称，例如 `protobuf` |
| 解码命令 | 接收标准输入、输出解码结果的可执行命令，例如 `protoc --decode_raw` |
| 编码命令 | 可选，用于把编辑后的文本重新编码回原始字节 |
| 自动启用 | 勾选后，命中该解码器规则的键会自动解码展示 |

3. 保存后，在键详情页选择该解码器即可查看解码结果；勾选「自动启用」则按规则自动应用。
4. 「帮助」按钮会回到本文档。

## 注意

- 解码命令以子进程方式在本机执行，命令内容由你自己填写，请只使用可信的可执行文件。
- 解码失败不会影响原始数据的展示与编辑。
- 相关配置保存在本机的 `preferences.yaml` 中，不随键值数据一起同步。
