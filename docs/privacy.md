# 隐私说明（Privacy）

本文件说明 KVPilot 在运行时会处理哪些数据。KVPilot 是 Tiny RDM 1.2.7 的社区延续分支，
以下内容针对本仓库的构建产物。

## 默认不收集任何数据

- 本分支**默认关闭**匿名使用统计（偏好设置中的「允许收集匿名数据」默认为关闭）。
- 本仓库的本地构建与默认发布构建**不注入**任何第三方统计 ID（`main.gaMeasurementID`
  为空），即使手动打开该开关，也不会有数据被上报。
- 不会上传你的连接配置、键值数据、命令历史或剪贴板内容。

## 保存在本机的内容

以下内容只写入本机磁盘，不会自动发送到任何服务器：

| 数据 | 位置 |
| --- | --- |
| 连接配置（地址、端口、用户名、密码） | 应用数据目录下的 `TinyRDM/connections.yaml` |
| 偏好设置（主题、语言、字体、解码器等） | 应用数据目录下的 `TinyRDM/preferences.yaml` |
| 窗口与标签页状态 | 本机 WebView 的 localStorage |

> 连接密码以明文保存在上述配置文件中，可参考上游 Tiny RDM 的行为。若你对此敏感，
> 请自行限制该目录的访问权限。

## 主动发起的网络请求

只有以下场景会离开本机：

| 场景 | 目标 | 频率 |
| --- | --- | --- |
| 检查更新（手动点击，或开启「自动检查更新」后启动时） | `api.github.com`（本仓库的 Releases API） | 每次检查 1 次 |
| 打开「使用指南 / 隐私策略 / 自定义解码」 | `github.com` | 仅在用户点击时 |
| 你主动连接的 Redis / KV 服务 | 你填写的地址 | 按你的操作 |

不会请求上游的 `tinyrdm.com`，也不会把更新检查结果用于任何追踪。

## 第三方组件

界面与后端包含 Vue、Naive UI、Vite、gin、go-redis、Wails 等开源组件，它们各自遵循
自己的许可证（MIT / BSD 等），运行时不进行额外的数据收集。
